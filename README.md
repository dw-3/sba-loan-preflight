# SBA Loan Preflight

**Status: specification and validation**

SBA Loan Preflight is a planned privacy-first browser application that will help small-business owners examine important repayment relationships using their own numbers and transparent arithmetic.

The first release is being defined from a calculator already published in [The $10 Million SBA Loan: What I'd Do Before Applying](https://www.diliawood.com/sba-loan-what-to-do-before-you-apply/). The legacy Ghost implementation is being audited as historical reference; the application will be rebuilt from a fresh product specification.

## Intended boundaries

- Educational borrower preparation, not institutional underwriting
- No approval, eligibility, or lending determination
- Browser-local calculation by default
- No account or sensitive-data collection for the public tool
- Documented assumptions, methodology, limitations, and validation cases
- No paid Loan-Ready Kit content or customer information

## Development record

The repository will use issues, reviewable branches, pull requests, tests, and versioned releases to document the work from domain problem to public software.

Product direction, domain model, validation, and UX decisions are led by Dilia Wood. Implementation is developed iteratively in collaboration with AI coding agents.
